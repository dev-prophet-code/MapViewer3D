MapViewer3D is not reachable

  1. Create a Console API key first (Settings → API Keys): scope maps = Read, scope bases = Read, everything else None. MapViewer3D cannot work without it.
  2. Install the companion container on the machine that runs the console (one command, see docker/README.md in the addon package): 
    sh install.sh
  3. The viewer listens on port 8795. By default it is private (only a browser on the server itself can open it). For other computers run the installer with MV_ADDR=0.0.0.0:8795: it sets a viewer password and you open that port for those browsers.
  4. If the console is served over https://, browsers block the plain-http viewer inside this page. Use Open in new tab or put the viewer behind the same TLS reverse proxy.
  5. Different address or port? Open Advanced above, enter it and press Apply.
